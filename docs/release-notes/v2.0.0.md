# Pokémon Play v2.0.0

Esta versão inaugura a linha pública 2.x e reúne os aprimoramentos recentes de segurança, controles e recuperação de preferências.

## O que mudou

- **Backups de save mais fáceis de distinguir:** a confirmação de restauração mostra o nome completo do backup, evitando confusão entre arquivos com nomes parecidos.
- **Remapeamento de controles mais claro:** ao tentar usar F12, reservado para voltar ao menu, o app explica o conflito e mantém a captura aberta para escolher outra tecla.
- **Preferências protegidas:** se o app não conseguir ler as preferências dos controles, Configurações exibe um aviso acessível. Salvar pede confirmação antes de substituir os dados desconhecidos, com **Não** selecionado por padrão. Recusar preserva o arquivo original.
- **Recuperação sem atrito:** preferências legadas legíveis e arquivos ainda não criados continuam salvando normalmente; depois de uma recuperação confirmada, salvamentos seguintes não repetem a pergunta.
- **Atualização da v171 para a v2:** instalações existentes da linha v171 recebem a v2.0.0 pelo verificador integrado. Próximas versões 2.x continuam sendo comparadas na ordem correta.
- **Publicação mais segura:** a automação de release agora rejeita tags que não apontem exatamente para o commit atual da branch padrão, evitando distribuir builds de código desatualizado.

## Verificações desta versão

- Cobertura Windows para aceitar ou recusar a substituição e comparar os bytes do arquivo antes/depois.
- Testes para confirmar que arquivos ausentes e preferências legadas não recebem confirmação indevida.
- Suíte de aplicação, launcher e pacote de release, incluindo probes dos cores GBA e Nintendo DS, executada antes da publicação.

## Instalação e atualização

Use o instalador, o pacote portátil ou a atualização integrada disponíveis nesta release. A atualização integrada preserva os dados do usuário e permite instalar a versão depois do download.
